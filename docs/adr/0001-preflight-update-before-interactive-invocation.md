# 在打开交互式 CLI 前执行更新预检

**状态：** 已接受

用户无参数启动 OMP 以打开交互式 CLI 时，OMP 入口先针对 OMP 自己配置的 stable 或 canary 频道同步执行自动更新，完成后再启动真实 OMP。带任意参数的调用不执行更新预检，直接透传给真实 OMP。包装命令通过用户级 PATH 目录置于原始 OMP 安装路径之前，从而保留 OMP 自己的安装、更新和回滚逻辑。如果更新在可配置的更新截止时间内（默认 60 秒）未完成，入口记录失败并启动当前已安装版本，不阻断正常使用。该决策将“启动后提醒更新”改为“打开交互式 CLI 前自动处理”，同时在网络或服务故障时保持可用。
